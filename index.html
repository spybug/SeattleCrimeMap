About Seattle Crime Map

This web application displays historic crime reports in Seattle using the official public Seattle Police Department (SPD) Socrata API.

How It Works

  • 500ft Radius: When you search an address or click the map, all crime reports within a 500ft radius over the past 3 years are retrieved.
  • Block Grouping: Crime reports in public data are generalized to block addresses (e.g. 55XX BLOCK OF 24TH AVE NW) for privacy. Each marker represents a block and shows the total crimes reported there.
  • Category Breakdown: Click on any block marker to reveal category sub-markers (Vehicle Theft, Burglary, Fraud, Assault, DUI, Pocket-picking, etc.) and filter the crime list accordingly.
